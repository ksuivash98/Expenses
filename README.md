# Личный финансовый кабинет

Современное веб-приложение для управления личными финансами. Работает полностью в браузере без сервера и сторонних библиотек.

## Возможности

- **Доходы** — добавление частями (зарплата, аванс, премия и др.), рост «свободных денег»
- **Конверты бюджета** — ручное распределение средств без автопроцентов
- **Покупки** — списание только из выбранного конверта
- **Кредиты** — учёт долга, платежи, история, закрытие
- **Коммунальные услуги** — ежемесячные записи, статусы, статистика
- **Финансовые цели** — прогресс и пополнение из конвертов
- **Календарь** — платежи по кредитам, ЖКХ и дедлайны целей
- **Аналитика** — Canvas-диаграммы, расчёт на лету
- **История** — единая лента операций
- **Настройки** — тёмная/светлая тема, валюта, экспорт/импорт JSON

## Технологии

- HTML5
- CSS3 (glassmorphism, адаптив)
- Vanilla JavaScript ES6 Modules
- LocalStorage
- Canvas API
- SVG

Без React, Vue, Angular, Bootstrap, Tailwind, Node.js, PHP и БД.

## Запуск

Откройте `index.html` в современном браузере.

Если браузер блокирует ES-модули с `file://`, поднимите локальный сервер:

```bash
# Python
python -m http.server 8080

# или VS Code / Cursor: Live Server
```

Затем откройте `http://localhost:8080`.

## Логика денег

```
Доход → Свободные деньги → Ручное распределение по конвертам
     → Расходы / кредиты / ЖКХ / цели → уменьшение баланса конверта
     → История и аналитика → Dashboard
```

Сумма распределения должна **точно** совпадать с остатком выбранного дохода.

## Данные

Все данные хранятся в LocalStorage под ключом `personal_finance_cabinet_v1`.

В настройках доступны:

- экспорт JSON
- импорт JSON
- полная очистка

## Браузеры

Chrome, Edge, Firefox, Safari (актуальные версии).
